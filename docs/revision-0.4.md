# 0.4 多张置顶贴图

用户需求：截图可以钉住，并同时存在多张。

正式发布补充：移除框选时中央的“拖动选择截图区域 · Esc 退出”文字；框选交互与 Esc 退出功能保留。

- 工具栏图钉按钮或 Ctrl+P，把当前截图（包括标注、当前显示的译图）钉到桌面，结束本次截图。
- 每次创建独立的置顶窗口，不以截图窗口为 Owner，不复用上一张图片。
- 拖动图片移动；右键复制或 Ctrl+C；悬停右上角关闭、右键关闭或 Esc 只关闭当前贴图。
- 继续截图可以增加贴图；退出轻截会关闭全部窗口。贴图不跨程序重启保留。
- 复用现有渲染、剪贴板和退出逻辑，不修改翻译或 GIF 数据流程。

验证仅使用合成图片和无前台窗口检查，不操作桌面、键鼠或剪贴板；实际拖动、置顶层级、混合 DPI 及复制粘贴仍需人工验收。

Release 构建成功，20 项核心测试、7 项 Python 测试及 14 项原生后台检查通过；需求/规范双轴只读审查未发现确认缺陷。已查看真实工具栏离屏图，图钉入口保持单排布局。
