# 0.2 工具栏与截图翻译修订

用户要求：工具栏按已确认的 HTML 和参考图调整；翻译的是当前截图，不弹出单独窗口。继续保持简洁，不影响用户正在进行的前端工作。

## 行为
- 白底、细线图标、绿色选中态及“完成 Enter”；顺序为选择、矩形、椭圆、箭头、笔、马赛克、文字、步骤、撤销、翻译、GIF、保存、取消、完成。
- 默认选择工具；颜色和粗细仅在标注工具或选中标注时显示。步骤编号、移动、撤销重做、删除保持可用。
- 翻译当前选区的原始截图，识别英文的像素位置，一次加载离线模型批量翻译，在对应区域覆盖中文。标注仍为独立图层，可继续编辑。
- 翻译中在工具栏提示进度并支持取消。失败保留原图和标注；关闭截图取消工作，不得在晚到的回调中打开窗口。
- 再次点击翻译按钮切换原图/译图，不重复推理；复制与 PNG 保存采用当前显示的底图加标注。
- 不涉及数据库或外部 API。现有翻译进程的 JSON 协议增加批量文本，保留单文本兼容。

## 验证约束
仅后台编译、测试和合成图的 WPF 离屏渲染；不启动交互窗口、不注册热键、不取用户桌面内容、不操作键鼠/剪贴板。检查 OCR 坐标、翻译映射、布局边界、取消和像素尺寸。完整 GUI 工作流及真实多屏 DPI 保留人工验收边界。

复杂背景只能根据文字附近颜色填充，无法恢复被英文遮挡的原始图像细节；不宣称图像修复或完美保留复杂版式。
