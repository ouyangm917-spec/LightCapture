# LightCapture 0.3.0 GitHub 发布

轻截 0.3.0，适用于 Windows 10/11 x64 的便携完整包。

## 本版更新

- 工具栏支持拖动，展开样式或翻译状态时保留手动位置。
- 重新设计 GIF 预览与导出界面，支持播放定位、首尾修剪、输出宽度和速度调整。
- 加入为轻截单独设计的应用图标，覆盖程序、窗口和系统托盘。
- 保留步骤标注及截图内英译中，译文直接回填当前截图。

## 下载与使用

下载附件 **LightCapture-0.3.0-win-x64.zip**，完整解压后运行 **LightCapture.exe**。更新前先从托盘退出旧版。请保留同目录 DLL、tessdata、offline 和 licenses 文件夹；GitHub 自动生成的 Source code 压缩包不是可直接运行的完整包。

完整包附带 .NET 运行库、英文 OCR、离线英译中模型和所需嵌入 Python 环境，无需配置 API Key 或另行安装 Python。OCR/翻译的原生组件需要 Microsoft Visual C++ 2015–2022 x64 运行库；本机已安装，干净 Windows 环境尚未验证。

默认快捷键 **Alt+A**，被占用时尝试 **Ctrl+Alt+A**；标注后按 **Enter** 复制图片。GIF 入口位于截图工具栏。
