# 轻截实现方案

## 已确认的交互

按快捷键，框选屏幕区域，在选区旁的工具栏直接编辑，按 Enter 复制图片，然后到目标应用粘贴。日常仅常驻托盘，不显示工作台。

工具包括选择、矩形、椭圆、箭头、画笔、文字、马赛克和自动编号步骤。选中图元后可移动、改颜色和粗细、删除；支持撤销重做。工具栏还提供 PNG 保存、英译中和 GIF。0.2 修订采用 HTML 原型中的白色单排、细线图标和绿色选中态；样式行按需显示。

翻译直接作用于当前选区：识别英文坐标，批量离线英译中，覆盖对应文字区域。保持截图窗口和标注，支持原图/译图切换，复制与保存使用当前显示结果，不打开独立翻译窗。

GIF 从当前选区开始录制，停止后打开小预览窗，可调整起止时间、输出宽度和播放速度，再保存循环 GIF。第一版限制每段 60 秒，默认 15 fps、最大录制宽度 1280，帧暂存磁盘以约束内存。

## 技术选择及影响

- C# / .NET 10 LTS / WPF，Windows x64；不修改系统 SDK、PATH 或安全策略。
- `LightCapture.Core`：图元及撤销历史、物理像素坐标、录制时间轴、GIF 容器。与桌面 UI 分开测试。
- `LightCapture.App`：托盘、全局热键、截屏、WPF 绘制、剪贴板、OCR 坐标、截图内翻译和录制预览。
- 英文 OCR 使用本地 Tesseract 和英文模型；避免免安装程序依赖 Windows OCR 的包身份。
- 英译中使用 Argos en→zh 1.9 简体模型、CTranslate2 和 SentencePiece；项目私有 Python 嵌入包经 stdin/stdout JSON 进行单次本地推理。仅翻译时启动，完成后退出，不安装系统 Python，不使用在线 API。
- 系统 GIF 编码器负责单帧压缩，应用写入帧时长和无限循环扩展，使用独立解码器验收。
- 不涉及数据库、已有接口或其他项目。配置存放当前用户目录；测试使用独立数据目录。
