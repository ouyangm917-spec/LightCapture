# LightCapture 0.4.0 正式发布

轻截 0.4.0：多张置顶贴图，适用于 Windows 10/11 x64。

## 更新

- 截图工具栏新增图钉按钮和 Ctrl+P，将当前截图（含标注或当前译图）钉在桌面，可同时存在多张。
- 贴图支持拖动、右键复制或 Ctrl+C；悬停右上角 ×、右键关闭或 Esc 单独关闭。退出轻截时全部关闭。
- 移除框选时中央的“拖动选择截图区域 · Esc 退出”提示文字，Esc 退出与框选操作仍保留。
- 保留截图原位离线英译中、步骤标注、可拖动工具栏及 GIF 录制/修剪导出。

## 下载使用

下载附件 **LightCapture-0.4.0-win-x64.zip**，完整解压后运行 **LightCapture.exe**。更新前请从托盘退出旧版。请保留同目录 DLL、tessdata、offline、licenses 文件夹；GitHub 自动生成的 Source code 压缩包不是可直接运行的完整包。

完整包包含 .NET 运行库、英文 OCR 数据、离线英译中语言模型及嵌入 Python 环境，不需要 API Key 或另装 Python。原生 OCR/翻译组件需要 Microsoft Visual C++ 2015–2022 x64 运行库；本机已安装，未在干净 Windows 环境完成验收。

默认截图快捷键 Alt+A，被占用时尝试 Ctrl+Alt+A。标注后 Enter 复制，Ctrl+P 钉住。
