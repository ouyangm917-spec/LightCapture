## 0.1 基础验证（仍由当前检查覆盖）

- 核心测试 20 项：编号自动递增、删除/撤销/重做、不可变图元、移动和命中、负屏幕坐标、修剪首尾、帧时间量化、GIF 字节结构和异常输入、OCR 文本清理。

- WPF GIF 编码结果经 WPF/GDI+ 独立读取：3 帧，64×40，100/150/200 ms，颜色正确、无限循环。

- 步骤编号渲染为 240×140 PNG，尺寸和标注像素正确。

- 5 张合成帧经实际录制管线落盘，截取中间 60%、缩放到 48×32、2× 速度导出 GIF；独立解码验证累计时长，关闭后会话缓存已回收。
- 取消离线翻译后，本次启动的子进程已退出，没有遗留推理任务。
- .NET 自包含 x64 发布成功；离线模型和运行库均包含在发布目录中。
- Python EXE 的 Authenticode 签名有效，签名者为 Python Software Foundation；依赖下载按固定摘要校验。
- 最终原生后台测试 6 项全部通过；审查修复后的 Release 自包含发布成功，没有编译警告。NuGet 审计元数据的沙箱网络警告已通过项目依赖恢复消除。
