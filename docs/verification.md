# 验证记录

日期：2026-11-09。Windows build 26200.9711，x64；项目 SDK 10.0.403。

## 已通过

- 核心测试 20 项：编号自动递增、删除/撤销/重做、不可变图元、移动和命中、负屏幕坐标、修剪首尾、帧时间量化、GIF 字节结构和异常输入、OCR 文本清理。
- Python 拆分测试 3 项：长文本不漏词、标识符与数字不丢失、空行不发送空推理批次。
- WPF GIF 编码结果经 WPF/GDI+ 独立读取：3 帧，64×40，100/150/200 ms，颜色正确、无限循环。
- Tesseract 对合成英文图片识别出 `Light Capture` 和 `Step 1: Open the file.`。
- 步骤编号渲染为 240×140 PNG，尺寸和标注像素正确。
- 实际本地模型将 `Click the Save button to save the screenshot.` 翻译为中文。首次样本调用约 1.5 秒，仅代表本机这一次短句，不作为通用性能承诺。
- 5 张合成帧经实际录制管线落盘，截取中间 60%、缩放到 48×32、2× 速度导出 GIF；独立解码验证累计时长，关闭后会话缓存已回收。
- 取消离线翻译后，本次启动的子进程已退出，没有遗留推理任务。
- .NET 自包含 x64 发布成功；离线模型和运行库均包含在发布目录中。
- Python EXE 的 Authenticode 签名有效，签名者为 Python Software Foundation；依赖下载按固定摘要校验。
- 最终原生后台测试 6 项全部通过；审查修复后的 Release 自包含发布成功，没有编译警告。NuGet 审计元数据的沙箱网络警告已通过项目依赖恢复消除。

用户要求不要抢屏幕、不要影响前端工作后，已立即结束前台测试进程；后续验证仅在后台进行。仅观察过设置界面，以下项目没有端到端 GUI 通过记录：

1. 全局快捷键与其他应用的冲突处理、真实框选和标注交互。
2. 完成复制后向微信/编辑器等外部应用粘贴，以及保存对话框。
3. 真实桌面区域录制、预览修剪交互及录制控制条排除。
4. 混合 DPI 多屏、HDR、干净系统 VC++ 运行库依赖。

用户空闲时可以自行按 README 的操作流程验证上述项目。代理不得为了补全这份记录而重新抢占前台。
