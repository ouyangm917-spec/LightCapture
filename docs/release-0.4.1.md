# LightCapture 0.4.1 正式发布

轻截 0.4.1，Windows 10/11 x64 离线完整包。

## 更新

- 贴图支持鼠标滚轮放大、缩小，范围 10%–400%，以鼠标位置为锚点；复制仍使用原图。
- 精简设置页，仅保留快捷键选择、离线翻译状态和取消/保存；移除宣传语、操作指引及技术参数。
- 快捷键冲突、保存失败时显示内联错误；写盘失败时恢复旧配置并尝试恢复旧快捷键，恢复失败会明确提示。
- 保留多张置顶贴图、截图原位翻译、步骤标注及 GIF 录制/修剪导出。

## 下载使用

下载附件 **LightCapture-0.4.1-win-x64.zip**，退出旧版后完整解压，运行 **LightCapture.exe**。请保留同目录 DLL、tessdata、offline、licenses 文件夹。GitHub 自动生成的 Source code 压缩包不是可直接运行的完整包。

包含 .NET 运行库、英文 OCR、离线英译中模型及嵌入 Python 环境，不需要 API Key 或另装 Python。原生 OCR/翻译组件需要 Microsoft Visual C++ 2015–2022 x64 运行库；本机已安装，干净 Windows 环境尚未完整验收。

默认 Alt+A 截图，被占用时尝试 Ctrl+Alt+A；Enter 复制，Ctrl+P 钉住；贴图上滚轮缩放，Ctrl+C 复制，Esc 关闭当前张。
