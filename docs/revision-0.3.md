# 0.3 工具栏拖动与 GIF 预览

用户反馈“工具栏不能够移动”，并要求优化截图中所示的 GIF 预览/导出页面。两项一起交付，继续遵守不操作用户前台、键鼠和剪贴板的约束。

## 范围与行为
- 工具栏左侧增加小型拖动柄；工具栏非交互空白处也可拖动。按钮、颜色和粗细控件保持原有点击行为。
- 初次仍靠近截图自动放置；手动拖动后，切换工具、展开颜色或显示翻译状态不再吸回选区旁。必要时只约束到当前屏幕工作区，支持负坐标屏幕。
- GIF 预览采用大预览区、右侧设置、底部操作的布局；统一白色、浅灰与绿色按钮，保留窗口系统标题栏及缩放。
- 保留开始/结束修剪、输出宽度、速度和循环 GIF 导出；提供播放/暂停和播放位置条，清晰显示保留时间与输出尺寸。
- 导出过程中显示进度、锁定相关编辑参数；关闭仍可取消导出并回收本次录制缓存。
- 不改截图、翻译模型、录制采样或 GIF 编码协议；不涉及数据库和外部 API。

## 验证
- 后台验证拖动命中排除按钮、负坐标/边界约束；实际系统拖动保留手动验收边界。
- 实际 GIF 控件离屏渲染，检查默认与较小窗口布局、播放/修剪/尺寸状态，以及合成帧导出。
- 编译和相关测试通过后审查并发布；不启动 GUI、移动鼠标或读取真实桌面。
