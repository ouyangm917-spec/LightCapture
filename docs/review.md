# 双轴审查

基线：`6aa9573bbdd6b6b627d4bcb38a61158605495bf0`。首次实现：`aeb88c9e738beea0900964e353d8779c9d3e18e7`。两个独立只读代理分别审查；主代理点验关键调用链并修复。没有进行前台操作。

## Standards

1. 录制/导出中点击托盘退出，原实现只停止录制或取消导出，没有在异步窗口关闭后退出进程。已增加退出状态，等待窗口和任务结束后 Shutdown；退出期间不再弹出 GIF 预览，也不接受新截图请求。
2. GIF 按钮启动录制窗口的同步异常没有事件边界。已复用现有捕获异常的完成入口，启动成功后再关闭截图窗口。录制期间的目录/编码异常原本已在异步录制处理器内捕获；补充统一失败回调，在退出期间避免弹窗。

以上为可靠性问题，未采用无关风格重构。

主代理另外补充了翻译取消回调，直接结束本次子进程，避免应用关闭时 UI Dispatcher 已退出而推理进程继续驻留；通过后台进程退出测试。`--self-test` 顶层异常写入 stderr，不弹出消息框。

## Spec

未发现已确认范围的静态主链路缺失。标注、步骤编号、复制/保存、离线 OCR/翻译、GIF 录制/修剪/速度/尺寸/循环均有实现。

录制控制条使用 `SetWindowDisplayAffinity` 排除，捕获使用 GDI；实际桌面的排除效果需要实机验证，不能以静态阅读判定成功。GUI 未验收边界继续保留。

修复后的编译和后台原生合成测试另记于 `verification.md`；没有把静态审查等同于真实桌面验收。
